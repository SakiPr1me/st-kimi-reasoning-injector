# 🔥 余温工具箱（注入/重roll/替换/轮询/修标签）

SillyTavern 综合扩展：思维链夺舍注入 + 智能自动重roll + 词汇替换 + API 额度轮换 + 标签自动修复，一个插件全包。

> 兼容 SillyTavern 1.13 ~ 1.18+（含旧 WebView），TauriTavern 同步支持。
> 界面三语：中文 / English / 한국어。

## 安装

SillyTavern → 扩展 → Install extension → 填入本仓库地址：

```
https://github.com/SakiPr1me/st-kimi-reasoning-injector
```

安装后在「扩展设置」里找到 **🔥 余温工具箱** 开启即可。建议搭配专用预设使用（预设作者：00余温V0811）。

## 功能总览

### ⚡ 思维链注入（破限核心）
- **KIMI 注入**（Meta 起手）/ **DS 注入**（We need 起手）/ **自定义模板**（可存多套）
- **step 1**：种子挂 `reasoning_content`，原生思维链不进正文，正文质量最高
- **step 2**：partial 正文续写，思维链进正文，破限更强、夺舍更稳（可双开）
- 思考强度可调（Kimi3 / DeepSeek 分开设置），DeepSeek 支持关闭思考
- 种子支持酒馆全部宏（`{{getvar}}`、`{{user}}` 等）

### 🔄 自动重roll（五重检测，全自动）

| 检测 | 触发条件 | 动作 |
|---|---|---|
| 英文思维链 | 夺舍失败开英文 | swipe 新分支 |
| 无思维链 | 直接出正文没思考 | swipe 新分支 |
| 空回复 | 断流零 token | swipe 新分支 |
| **半截楼** | 生成结束仍无截断标记（如 `<mutter>`）——思维链或正文被截断 | swipe 新分支继续 |
| 思考太短 | partial 思考低于阈值 | 截断重roll |

- 连续上限保护（默认 30 次）、横幅一键 ⏹ 停止、手动 swipe 自动恢复
- **完整生成提示音**：回复带完整截断标记时"叮咚"提醒你——8 种音色可选可试听（柔和叮咚/八音盒旋律/长铃余音等），手机浏览器也正常响

### ✂️ 自动截断
流式中检测到指定标记（默认 `<mutter>`）立即停止生成，省 token。

### 🎨 思维链美化折叠
`<scene>` 前的思考内容收进优雅折叠框，流式同步不闪烁；折叠区固定高度滚动（长思维链不撑爆楼层）；实时计时精确到秒。

### 🔤 词汇替换（像酒馆正则一样即时生效）
- 简单/正则两种模式，显示层与提示词层独立开关
- 「应用至以往所有」批量改历史 + 一键回退
- 显示替换在字符串层完成，绝不破坏其它插件的美化结构

### 🏗 标签修复（原 st-tag-auto-fixer）
- 缩进式标签树配置，AI 输出缺闭合/缺开标签/标签名残缺/同级穿插全自动修
- **👁 幻影 diff 预览**：修复处红 − 绿 + 行级对比，纯预览不改数据；上一处/下一处跳转
- 三种工作模式：每轮自动修复 / 每轮自动扫描（只标不改）/ 手动修复
- 修复最后一条 / 修复全部楼层 / 单条回退 / 全部回退
- 入口可选：输入框旁图标 / 悬浮球 / 扩展菜单 / `/fix-tags` 命令

### 🔌 API 池（额度轮换，多号党福音）
- 维护多条 Custom (OpenAI 兼容) 接口：模型名 + URL + 密钥 + 已用天数
- 报错命中 `limit/quota/rate` 关键词 → 弹横幅询问切换，或开启**自动切换**
- 切换只改 URL + 密钥 + 模型名三项，预设/采样参数分毫不动
- 扩展菜单常驻「⇄ 切换下个API」入口（可在设置中隐藏）

### 🧰 其它
生成完保持滚动位置（不跳顶）· 楼层 t/s 速度显示 · 正文换行自动修正（可回退）· Name 注入 · 全部界面三语

## 手机端

自适应布局；提示音通过首次触摸页面解锁音频（点一次发送即可），之后锁屏挂机也能听到。
